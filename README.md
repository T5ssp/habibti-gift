# حبيبتي ♡

عالم رومانسي عربي باتجاه RTL: قمر وبحيرة عند الاستقبال، مدخل بالرمز، مدينة خيالية، وذكريات ورسائل ومفاجآت قابلة للتخصيص. يعمل الموقع باستضافة ثابتة، دون خادم خلفي أو قاعدة بيانات أو مكتبات واجهة كبيرة.

## تنزيل الملفات

- [المشروع كاملًا بصيغة ZIP](https://github.com/T5ssp/habibti-gift/raw/refs/heads/main/downloads/habibti-gift.zip)
- [نسخة HTML مستقلة](https://github.com/T5ssp/habibti-gift/raw/refs/heads/main/dist/habibti-standalone.html)
- دليل التشغيل والنشر هو هذا الملف.

## التشغيل محليًا

من مجلد المشروع:

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

افتح `http://127.0.0.1:8000` في المتصفح، واضغط «ابدئي الرحلة»، ثم أدخل **262**. الرمز جزء من التجربة، وتتحقق منه الواجهة في جهاز الزائر؛ ليس نظام مصادقة ولا يحمي الملفات أو المعلومات الخاصة.

## التخصيص من داخل الموقع

افتح «إعدادات الهدية» من القائمة الجانبية، ثم «جهّز هديتك بلمستك». تتضمن الإعدادات:

- إضافة الذكريات الزمنية وتعديل تواريخها وعناوينها ووصفها وصورها أو حذفها.
- تخصيص الأظرف الستة، وفصول كتاب حكايتنا وهوامشه السرية، والرسالة الأخيرة.
- إضافة حتى ست صور للألبوم مع أوصافها، ورفع تسجيل صوتي حتى 3 ميغابايت، واختيار صورة البازل.
- كتابة أسباب الحب، ثم تحميل نسخة مستقلة تحتوي على الصور والصوت والنصوص المخصصة.

مشاهد الذكريات الافتراضية رسومات افتتاحية؛ استبدلها بصوركما وتواريخكما. التعديلات تحفظ في `localStorage` على المتصفح والجهاز الحاليين، ولا تُرفع إلى خدمة خارجية. مسح بيانات الموقع أو تغيير المتصفح قد يزيلها. إذا امتلأت مساحة التخزين أو تعذّر الوصول إليها، تعرض الواجهة رسالة ويبقى التعديل متاحًا للزيارة الحالية؛ حمّل نسخة الهدية قبل إغلاقها.

بقيت وظائف النسخة الأصلية ضمن التصميم الجديد: مرصد النجوم، الكتاب وهوامشه، صيدلية المشاعر، الاختبار والزر الهارب، الموسيقى، الختم الشمعي، تنزيل البطاقة بصيغة PNG، عجلة المفاجآت، أسباب الحب، الصور والصوت، البازل، الكوبونات، اقتراح الموعد والعد التنازلي، حديقة الورود، الرسالة اليومية واختيار المزاج.

## الملفات والنسخة المستقلة

```text
index.html                     مدخل الموقع
assets/css/                    الأنماط والتجاوب والمؤثرات
assets/js/                     التفاعلات والتخصيص والموسيقى والتصدير
assets/images/                 سبع رسومات أصلية بصيغة WebP دون نصوص مدمجة
assets/fonts/                  خطوط Amiri وIBM Plex Sans Arabic المحلية وتراخيصها
backup/index-original.html     نسخة مطابقة للملف الأصلي قبل إعادة التصميم
dist/habibti-standalone.html    نسخة HTML مجمعة جاهزة للمشاركة
tools/build_standalone.py      توليد النسخة المجمعة ومصدر التصدير داخل الموقع
tests/smoke.py                 اختبارات المتصفح
```

بعد تغيير HTML أو CSS أو JavaScript أو الصور أو الخطوط، شغّل:

```bash
python3 tools/build_standalone.py
```

الأداة تعتمد على مكتبة Python القياسية، وتحدّث `dist/habibti-standalone.html` و`assets/js/export-source.js`. لا تعدّل الملف الأخير يدويًا. النسخة في `dist` تجمع الأنماط والبرامج والصور والخطوط داخل ملف واحد؛ أما زر «تحميل نسخة الهدية» فيضيف إليها تخصيصات المتصفح الحالية. تنزيل الملف لا ينشره على الإنترنت.

## النشر على GitHub Pages

أُضيف مسار نشر آلي في `.github/workflows/deploy-pages.yml`. من [إعدادات Pages](https://github.com/T5ssp/habibti-gift/settings/pages)، اختر **GitHub Actions** في **Build and deployment → Source**. يعمل النشر عند كل تحديث لفرع `main`، ويمكن تشغيله يدويًا من تبويب **Actions → Publish Habibti to GitHub Pages → Run workflow**.

يُحدّث المسار النسخة المستقلة ثم ينشر `index.html` و`assets` فقط، مع `.nojekyll`؛ لا ينشر النسخ الاحتياطية أو اختبارات التطوير أو أرشيف ZIP. يظهر رابط الموقع في خطوة النشر عند نجاحها. العنوان المتوقع دون نطاق مخصص هو `https://t5ssp.github.io/habibti-gift/`؛ وجود هذا العنوان في الدليل لا يثبت اكتمال النشر.

للنشر الثابت اليدوي، ارفع `index.html` ومجلد `assets` معًا مع الحفاظ على المسارات. إذا عدّلت الأصول، أعد توليد النسخة المستقلة قبل رفعها حتى تعكس التنزيلات آخر التغييرات. ويمكن أيضًا نشر ملف `dist/habibti-standalone.html` منفردًا بعد تسميته `index.html`.

## الموسيقى

مصدر الموسيقى الأصلي محفوظ: فيديو YouTube بالمعرّف `IPuWTXlSrTw`. لا يبدأ البث بمجرد فتح الموقع أو إدخال الرمز؛ يبدأ بعد الضغط الصريح على تشغيل الموسيقى. تتطلب خدمة YouTube اتصالًا بالإنترنت والسماح بها في الشبكة، وقد تؤثر قيود الفيديو أو التضمين في التشغيل. الصور والخطوط والتفاعلات الأساسية محلية.

في بيئة التطوير الحالية أعاد وسيط الشبكة خطأ `CONNECT 403` لمصدر البث، لذلك لم يُثبت تشغيل YouTube الحي. تختبر الاختبارات بروتوكول الأزرار والتقدم والصوت بمشغل محاكى، وتختبر تشغيل التسجيل الصوتي المحلي المرفوع بصورة مستقلة.

## الاختبارات

تحتاج الاختبارات إلى Python مع حزمة Playwright وChromium. تأتي هذه الأدوات مثبتة في بيئة المشروع الحالية. اترك الخادم المحلي يعمل، ثم شغّل من جذر المشروع:

```bash
python3 tests/smoke.py --url http://127.0.0.1:8000
```

يمكن تحديد Chromium بمسار مختلف باستخدام `--chromium`. يستخدم الاختبار `/usr/bin/chromium` افتراضيًا، ويكتب التقرير واللقطات في `tests/artifacts/`.

تغطي الاختبارات الاستقبال والدخول والتنقل، والتخصيص والتخزين، والتفاعلات القديمة والجديدة، ورفع الصور والصوت، وتصدير الهدية والبطاقة، وأخطاء JavaScript والموارد المحلية، ومقاسات 1440×900 و1280×720 و390×844 و360×800. الطلبات الخارجية محجوبة أثناء الاختبار، وبث YouTube مستثنى كما هو موضح أعلاه. يدعم الموقع إعداد تقليل الحركة في الجهاز.

آخر تحقق آلي: **19 مجموعة ناجحة، 0 إخفاقات، 0 مجموعات متخطاة**. التقرير محفوظ في `tests/validation-report.json`. اختُبرت النسخة المصدرة على أصل محلي جديد دون طلب أصول إضافية؛ يمنع متصفح البيئة الانتقال المباشر إلى `file://`، لذا لم يُختبر فتحها بهذه الطريقة هنا. بث YouTube الحي مستثنى من هذا التحقق.
